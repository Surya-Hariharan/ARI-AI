# ARI

ARI is a modern frontend project for an AI control interface with a clean, premium UI and multi-page flow.

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS

## Project Structure

- frontend: main web app
- docs: supporting documentation

## Getting Started

1. Go to the frontend folder.
2. Install dependencies.
3. Start the development server.

```bash
cd frontend
npm install
npm run dev
```

## Build

```bash
cd frontend
npm run build
```
